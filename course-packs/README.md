# Course Packs

This directory contains optional curriculum data for EduBoard's generic Course Pack importer.

A Course Pack may be institution- or course-specific. Its presence here must not make the core application assume that every teacher works at that institution, teaches that subject, uses those standards, or needs those student fields.

## JUST Applied Academic & Professional English 2026–27

`just-applied-english-2026-27.coursepack.json` is the course-specific pack for the supplementary/optional JUST Zhangjiagang curriculum.

It contains:

- 2 terms;
- 34 planned 90-minute sessions (15 Term 1 + 19 Term 2);
- 9 UENG standards;
- R1–R5 reusable rubrics;
- major assessment placeholders and recommended weighting notes;
- the course's nine optional student-profile fields;
- source-of-truth planning notes/resources.

The three removable Term 2 extension sessions are marked `[FLEX]`.

The pack deliberately does **not** contain detailed PPTs, readings, worksheets or activity banks yet. Those belong to the later teaching-material phase after the curriculum architecture is stable.

Import it from **Settings → Data and security → Course Pack** and explicitly map each term to the intended existing EduBoard class.
