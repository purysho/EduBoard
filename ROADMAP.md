# Roadmap

EduBoard's guiding idea is a **local-first teacher operating system**: everything a
teacher needs for classes, grading, assessment, communication, resources, and classroom
management, running entirely offline with no account and no server.

## Shipped in v0.2.0

Parent communication tracking, assignment submissions, seating charts, multi-term
composite grading, exit tickets, a resources library, and score comments — see
[CHANGELOG.md](CHANGELOG.md) for the full list.

## Under consideration for a future release

None of these are committed or scheduled — they're ideas being weighed against
EduBoard's offline, no-account, no-server design, which some (cloud sync, parent
accounts) sit in real tension with.

- AI-assisted lesson planning
- AI-drafted report-card comments
- A parent-facing portal
- Student login accounts
- Cloud sync between devices
- A mobile companion app
- Deeper analytics dashboards
- Timetable / schedule management
- Attendance via QR-code scanning

Have an idea, or want to weigh in on one of these? Open an issue — see
[SECURITY.md](SECURITY.md) instead if it's a security report rather than a feature idea.
